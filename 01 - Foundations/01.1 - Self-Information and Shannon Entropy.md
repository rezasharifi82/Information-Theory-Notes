# 01.1 — Self-Information and Shannon Entropy

## 1. Shannon's Communication Paradigm

In his groundbreaking 1948 paper, *"A Mathematical Theory of Communication"*, Claude Shannon abstracted communication from physical engineering into a universal mathematical framework:

![[Shannon-Communication-System.excalidraw|850]]

The central question of information theory is:
> *How much information is produced by a source, and what is the fundamental minimum number of binary digits needed to represent that information reliably across any channel?*

To answer this, we must quantify the concept of **uncertainty** and **information content**.

---

## 2. Self-Information (Surprise)

Consider an event $x$ that occurs with probability $P(X = x) = p(x)$. How much "information" or "surprise" do we gain upon observing that $x$ has occurred?

> [!intuition] Intuitive Axioms of Information Content
> 1. **Inverse monotonicity:** An event that is certain ($p=1$) provides zero new information: $I(1) = 0$. Rare events ($p \to 0$) convey massive surprise: $I(p) \to \infty$.
> 2. **Non-negativity:** $I(x) \ge 0$ for all $p(x) \in (0, 1]$.
> 3. **Additivity of independent events:** If two events $x$ and $y$ are independent ($p(x, y) = p(x)p(y)$), the total surprise must be the sum of their individual surprises:
>    $$I(x, y) = I(x) + I(y)$$

The only continuous function satisfying $f(p_1 \cdot p_2) = f(p_1) + f(p_2)$ with $f(1) = 0$ is the logarithm.

> [!definition] Definition 1.1: Self-Information (Surprise)
> For an event $x$ with probability $p(x) > 0$, the **self-information** is defined as:
> $$I(x) \triangleq \log_2 \left(\frac{1}{p(x)}\right) = -\log_2 p(x)$$
> * If base $2$ is chosen, the unit is **bits** (or **shannons**).
> * If natural base $e$ is chosen, the unit is **nats** ($1 \text{ nat} = \log_2(e) \approx 1.4427 \text{ bits}$).
> * If base $10$ is chosen, the unit is **Hartleys** or **dits**.

---

## 3. Shannon Entropy

Entropy is the *expected value* (average) of the self-information over all possible outcomes of a discrete random variable.

> [!definition] Definition 1.2: Shannon Entropy
> Let $X$ be a discrete random variable taking values in alphabet $\mathcal{X}$ with probability mass function $p(x) = \mathbb{P}(X = x)$. The **Shannon entropy** $H(X)$ is:
> $$H(X) \triangleq \mathbb{E}[I(X)] = \sum_{x \in \mathcal{X}} p(x) \log_2 \left(\frac{1}{p(x)}\right) = -\sum_{x \in \mathcal{X}} p(x) \log_2 p(x)$$
> *Convention:* By continuity, $0 \log_2 0 \triangleq \lim_{p \to 0^+} p \log_2 p = 0$.

> [!note] Fundamental Properties
> * $H(X)$ depends **only on the probability distribution** $p(x)$, not on the actual numerical values that $X$ takes.
> * Entropy measures:
>   1. The **average uncertainty** before observing $X$.
>   2. The **average information** gained upon observing $X$.
>   3. The **optimal average code length** (in bits) required to compress realizations of $X$ without loss (Shannon's Source Coding Theorem).

---

## 4. The Binary Entropy Function $H_b(p)$

For a binary random variable $X \in \{0, 1\}$ distributed as $\text{Bernoulli}(p)$:
$$\mathbb{P}(X = 1) = p, \quad \mathbb{P}(X = 0) = 1 - p$$

> [!definition] Definition 1.3: Binary Entropy Function
> The binary entropy function $H_b: [0, 1] \to [0, 1]$ is:
> $$H_b(p) \triangleq -p \log_2 p - (1-p) \log_2 (1-p)$$

```
     H_b(p) (bits)
      1.0 +                *****
          |             *         *
      0.8 +           *             *
          |         *                 *
      0.5 +        *                   *
          |       *                     *
      0.0 +------*-----------------------*----> p
                0.0         0.5         1.0
```

> [!property] Properties of $H_b(p)$:
> 1. **Symmetry:** $H_b(p) = H_b(1-p)$.
> 2. **Extrema:** $H_b(0) = H_b(1) = 0$ (no uncertainty).
> 3. **Maximum:** $\frac{d}{dp} H_b(p) = \log_2 \left(\frac{1-p}{p}\right) = 0 \implies p = \frac{1}{2}$, where $H_b\left(\frac{1}{2}\right) = 1\text{ bit}$.
> 4. **Strict Concavity:** $\frac{d^2}{dp^2} H_b(p) = -\frac{1}{\ln 2}\left(\frac{1}{p} + \frac{1}{1-p}\right) < 0$ for all $p \in (0, 1)$.

## 5. Fundamental Bounds on Entropy

> [!theorem] Theorem 1.1: Upper and Lower Bounds on Entropy
> Let $X$ be a discrete random variable supported on finite alphabet $\mathcal{X}$ with cardinality $|\mathcal{X}|$. Then:
> $$0 \le H(X) \le \log_2 |\mathcal{X}|$$
> * **Lower Bound Equality:** $H(X) = 0$ if and only if $X$ is deterministic ($\exists x_0 \in \mathcal{X}$ such that $p(x_0) = 1$).
> * **Upper Bound Equality:** $H(X) = \log_2 |\mathcal{X}|$ if and only if $X$ is uniformly distributed ($p(x) = \frac{1}{|\mathcal{X}|}, \forall x \in \mathcal{X}$).

> [!proof] Proof of the Upper Bound (via Jensen's Inequality)
> The function $f(t) = \log_2 t$ is strictly concave since $f''(t) = -\frac{1}{t^2 \ln 2} < 0$.
> By **Jensen's Inequality**, for any random variable $Z$ and strictly concave function $f$:
> $$\mathbb{E}[f(Z)] \le f(\mathbb{E}[Z])$$
> Let $Z = \frac{1}{p(X)}$. Then:
> $$H(X) = \mathbb{E}\left[\log_2 \frac{1}{p(X)}\right] \le \log_2 \mathbb{E}\left[\frac{1}{p(X)}\right]$$
> Expanding the expectation on the right-hand side:
> $$\mathbb{E}\left[\frac{1}{p(X)}\right] = \sum_{x \in \mathcal{X}} p(x) \cdot \frac{1}{p(x)} = \sum_{x \in \mathcal{X}} 1 = |\mathcal{X}|$$
> Therefore:
> $$H(X) \le \log_2 |\mathcal{X}|$$
> Equality holds in Jensen's inequality if and only if $Z = \frac{1}{p(X)}$ is constant almost surely, meaning $p(x) = \frac{1}{|\mathcal{X}|}$ for all $x \in \mathcal{X}$ (uniform distribution).

## 6. Worked Examples

> [!example] Example 1.1: 8-Sided Die (Fair vs. Loaded)
> Let $X$ denote the roll of an 8-sided die ($\mathcal{X} = \{1, 2, \dots, 8\}$).
> 
> **Case A (Fair Die):**
> $p(x) = \frac{1}{8}$ for all $x$.
> $$H(X) = \sum_{x=1}^8 \frac{1}{8} \log_2 8 = \log_2 8 = 3 \text{ bits}$$
> *Interpretation:* Exactly 3 binary questions (e.g., standard binary search: "is it $>4$?", "is it odd?") are necessary and sufficient to determine the outcome.
> 
> **Case B (Loaded Die):**
> Let $p(1) = \frac{1}{2}$, and $p(2) = \dots = p(8) = \frac{1}{14}$.
> $$\begin{aligned}
> H(X) &= -\frac{1}{2}\log_2\left(\frac{1}{2}\right) - \sum_{x=2}^8 \frac{1}{14}\log_2\left(\frac{1}{14}\right) \\
> &= \frac{1}{2}(1) + \frac{7}{14}\log_2(14) \\
> &= 0.5 + 0.5 \log_2(14) \approx 0.5 + 0.5(3.807) \approx 2.404 \text{ bits}
> \end{aligned}$$
> The loaded die produces less uncertainty ($2.404 < 3.000$ bits) because outcome $1$ is highly predictable.

---

> [!example] Example 1.2: Huffman Preview on 4-Symbol Alphabet
> Suppose a source generates symbols with probabilities:
> $$p(A) = \frac{1}{2}, \quad p(B) = \frac{1}{4}, \quad p(C) = \frac{1}{8}, \quad p(D) = \frac{1}{8}$$
> The entropy is:
> $$H(X) = \frac{1}{2}(1) + \frac{1}{4}(2) + \frac{1}{8}(3) + \frac{1}{8}(3) = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 \text{ bits}$$
> Notice that if we assign prefix code words with length $\ell(x) = \log_2 \frac{1}{p(x)}$:
> * $A \to 0$ (length 1)
> * $B \to 10$ (length 2)
> * $C \to 110$ (length 3)
> * $D \to 111$ (length 3)
>
> The average code length is:
> $$L = \sum_{x} p(x)\ell(x) = 1.75 \text{ bits} = H(X)$$
> This achieves the exact Shannon entropy bound! (See [[02.1 - Prefix Codes and Kraft-McMillan Inequality|Module 2: Source Coding]]).

## 7. Summary & Key Takeaways

1. **Surprise:** $I(x) = \log_2 \frac{1}{p(x)}$ measures the information in a single event.
2. **Entropy:** $H(X) = \mathbb{E}[I(X)]$ is the expected uncertainty.
3. **Range:** $0 \le H(X) \le \log_2 |\mathcal{X}|$. Deterministic is minimal, uniform is maximal.
